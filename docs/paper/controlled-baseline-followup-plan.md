## A. 짝지은 차이 (AIDA current − 기준선)

- 같은 조건·같은 시드에서 차이 → 조건 평균 → 시드 간 평균. **조건은 고정 벤치마크로 보고 재표집하지 않는다**(조건 간 상관을 독립 표본으로 세지 않기 위해).
- 구간: 시드별 평균 차이의 **탐색적 t 구간**(시드 3개면 자유도 2). 단일 시드 묶음은 구간 없음.
- 함께 적는 것: **차이가 양수인 시드 수 / 전체 시드 수**, **차이가 양수인 조건 수 / 전체 조건 수**(시드 평균 차이 기준).
- **구간이 0을 빼는 것만으로 우위를 선언하지 않는다.**
- 동점 씨앗은 20260929로 고정. 씨앗 1~10은 별도 민감도로 보고하고, 조건 × 학습 시드 × 동점 씨앗을 독립 반복처럼 합치지 않는다.
- 기준선: 전체 라벨 ObjectLab, 전체 라벨 1−IoU, 전체 라벨 무작위(기대값). 특히 KITTI→COCO의 current − ObjectLab.

## B. k 민감도

- 두 계열을 모두 집계한다.
  - AIDA 지목 수 기준 k = 5·10·20·50% (최소 1)
  - **전체 라벨 수 기준 k = 1·2·5%** — k 정의가 AIDA에 유리한지 보기 위한 계열
- 분모 k·최소 1·동점 규칙·silent 조건 제외는 그대로. 후보가 k보다 적은 수와 실제 분모 변형을 병기한다.
- 무작위 기대값은 후보 부족 시 `min(k, 후보 수)/k`를 반영한다.
- finding 단위 표와 고유 라벨 단위 표를 나눈다(k가 커지면 같은 라벨의 finding이 겹칠 수 있다).
- 조건별 IoU 0 라벨 수와 `k > IoU 0 수` 여부를 기록한다. IoU 0 라벨은 빼지 않는다.

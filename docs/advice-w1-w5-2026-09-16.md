> **결정 기록이 아니다.** 사용자가 정하기 전에 코파일럿 CLI에 물어본 답과, 그 답을 Claude가 공식
> 원문·저장소 문서와 대조한 결과다. 코파일럿은 **읽기와 라이선스 공식 도메인 조회만** 허용하고
> 명령 실행·파일 수정은 막은 채 돌렸다. **법적 판단이 아니다.**

## 1. W1 — 라이선스 원문

### 공식 원문 대조 (Claude가 직접 조회, 2026-09-16)

| 항목 | 공식 원문에서 확인한 것 | 출처 |
|---|---|---|
| BDD100K | 허용 문장: "educational, research, and not-for-profit purposes, without fee". 상업 사용은 BDD·BAIR Commons 회원과 그 계열사에게. 복제·수정·배포본에 저작권 고지 문단 유지 | `github.com/bdd100k/bdd100k` `doc/source/license.rst` |
| Ultralytics (가중치 포함) | "All Ultralytics YOLO trained models fall under the AGPL-3.0 License by default." 이 조건이 내부 사용·R&D에도 적용된다고 적는다. 무료 AGPL 경로의 예로 개인 프로젝트·학습·실험을 든다 | `ultralytics.com/license` |
| KITTI | "Creative Commons Attribution-NonCommercial-ShareAlike 3.0". 객체 과제 페이지: "training data ... may be used for learning the parameters of the algorithms." 내려받는 사람은 등록하고 사용 목적을 밝혀야 한다 | `cvlibs.net/datasets/kitti/`, `.../user_login.php?dataset=object` |

### 코파일럿이 짚은 것 (대조 결과 맞음)

- BDD100K 허용 문구와 상업 조건, 고지 유지 의무 — 원문과 같다.
- Ultralytics가 **학습·미세조정한 모델까지** AGPL-3.0 또는 엔터프라이즈 라이선스 대상이라고 주장한다 — 원문과
  같다. AGPL 본문상 수정 없이 로컬에서 실행하는 데는 조건이 거의 없고, 수정본을 **네트워크로 제공하면**
  소스 제공 의무가 핵심이라는 해석.
- KITTI는 CC BY-NC-SA 3.0이고, 학습 데이터로 파라미터를 학습해도 된다는 정책 문장이 있다 — 원문과 같다.
- 세 항목 모두 목적 A에 대한 원문 수준 적합성은 **"불명확"** 이라고 했다. 공통 쟁점은 "나중에 사업화할
  수 있는 개인 연구가 지금 비영리·비상업인가".

### 코파일럿이 놓친 것 (Claude)

- **BDD100K 라이선스 문장의 대상이 "this software and its documentation"이다.** 이 파일이 **데이터(이미지·
  라벨)** 에도 적용되는 라이선스인지, 도구 코드와 문서에만 적용되는지가 문장만으로는 분명하지 않다.
  데이터 내려받기 페이지(`bdd-data.berkeley.edu`)는 코파일럿도 열지 못했다. **데이터에 붙는 약관을
  별도로 확인해야 한다.**
- **우리 자(KITTI로 학습한 `ruler`) 자체가 Ultralytics 주장상 AGPL-3.0 대상이다.** 동시에 학습 자료는
  CC BY-NC-SA다. 로컬 연구용으로 쓰는 한 원문 수준의 충돌은 드러나지 않지만, **가중치를 공개하거나 서비스로
  열면** 두 조건(AGPL 소스 제공, NC·SA)을 함께 따져야 한다.
- Ultralytics 페이지가 비영리 연구에 대해 "if the project is completely disclosed"라는 조건을 붙인
  문구가 있다 — 개인 프로젝트 조항과 어느 쪽에 해당하는지는 해석 문제다.

### 법률 검토로 넘길 질문

1. 사업화 가능성이 있는 개인의 연구 시제품이 BDD100K의 "not-for-profit", KITTI의 "NonCommercial"에
   해당하는가.
2. BDD100K `license.rst`가 데이터에도 적용되는가, 데이터 약관은 따로 무엇인가.
3. 판정 기록·상자 좌표·평가 보고서를 공개하면 데이터의 수정물·배포에 해당하는가(고지 의무, SA).
4. KITTI로 학습한 가중치가 CC 라이선스의 "Adaptation"인가, Ultralytics AGPL과 동시에 지킬 수 있는가.

## 2. W5 — 사전 등록 초안 D1~D8에 대한 코파일럿 의견

| D1 | BDD100K는 라이선스 확인이 끝났을 때만. 아니면 **KITTI로 시작** | **뒷부분은 채택하면 안 된다.** KITTI는 자의 학습 도메인이고 소비된 개발 데이터로 적어 두었다 — [next-evaluation-proposal.md](next-evaluation-proposal.md) 4절, [evaluation-data.md](evaluation-data.md) 원장. KITTI로 하면 "손대지 않은 데이터셋" 조건을 어긴다 |
| D2 | Car만 | 초안의 설명과 같다 |
| D3 | 이미지 단위, 장면 묶음은 주행 영상이면 나중에. 씨앗 고정 | BDD100K는 영상 키프레임이라 장면 묶음이 필요할 수 있다 — **판정 전에** 정해야 하고, 쓰려면 구현이 먼저다 |
| D4 | **v2를 1차로** — v1은 생성과 순서가 섞이고, v2는 후보 생성만 잰다 | 근거가 초안 3절 표와 맞는다. 결정은 사용자 몫 |
| D5 | N=60, K=50 | 드라이런 표로 N=60·K=50은 판정 282건(누락 60 포함, 약 24분). 누락 층을 빼면 약 222건(약 19분)이다. 코파일럿은 빼고도 24분이라 했는데 숫자가 맞지 않는다 |
| D6 | **누락 층은 같은 세션에 넣지 않는다** | 타당한 방향이지만 **지금 코드는 한 N이 모든 층에 쓰인다.** 빼려면 (가) 누락 층을 판정 대상에서 끄는 옵션을 구현하거나 (나) Q-C를 나중에 별도 평가로 돌려야 한다 |

| D8 | 1인 판정으로 **탐색으로** 지금 실행, 최종 판단은 2인 이상 뒤 | 초안 1절과 같다 |

### 코파일럿이 "고쳐야 할 결함"이라고 한 것

| 지적 | 대조 |
|---|---|
| D4가 v1/v2를 섞는다 | 초안 3절에 두 선택이 무엇을 재는지 표로 갈라 적었다 — **해당 없음** |
| 빈칸이 남아 있어 사전 등록이 아니다 | 맞다 — **의도한 상태**(초안) |
| 단일 판정자인데 성공·실패 문구가 있다 | 초안은 1인이면 탐색이고 성공·실패를 주장하지 않는다고 적었다. D7 표에 "Δ를 정할지"가 선택지로 있을 뿐 — **표현을 더 분명히 할 여지는 있다** |
| `same_candidate_set`을 미리 안 고정하면 부트스트랩이 막힌다 | 초안 6절 3번이 `require_same_candidates=False`를 이미 고정했다 — **해당 없음** |
| 표본 층을 참 오류 비율로 읽는 표현 | 초안 5·7절이 참 오류 비율로 부르지 않는다고 적었다 — **해당 없음** |
| 결과를 보고 순서를 바꾸는 사후 편향을 명문화 | 초안 7절에 있다 — **해당 없음** |

**정리:** 코파일럿의 D2·D4·D8 판단과 "누락 층 분리"라는 방향은 쓸 만하다. D1의 KITTI 대안은 문서화된
경계와 충돌하고, D5 시간 추정과 D7 부호에는 오류가 있으며, 결함 목록 6개 중 4개는 초안에 이미 있는 것을
못 본 것이다.

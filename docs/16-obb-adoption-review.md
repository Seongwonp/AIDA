# 16. OBB 도입 검토 문서

## 결론 요약

현재 MVP는 KITTI/YOLO의 2D axis-aligned bounding box를 기준으로 돌아간다. 따라서
회전각 오류를 "진짜 기울어진 박스"로 학습시키지 못하고, 회전된 네 꼭짓점을 다시
감싸는 수평/수직 박스로 근사한다. 이 방식은 기존 13개 조건 결과를 빠르게 만든 장점이
있지만, 회전 방향 정보가 사라지고 박스가 커지는 효과가 섞이는 한계가 있다.

당장 전체 모델을 OBB로 교체하지는 않는다. 대신 MVP에서는 기존 `rotation` 조건을
호환용으로 보존하고, 다음 실험부터는 중심점 이동(`translation_x`, `translation_y`)과
스케일(`scale`) 조건을 별도 후보로 추가한다. OBB는 본선/후속 연구 단계에서 비용과
데이터 포맷을 확인한 뒤 도입한다.

## 현재 코드 기준 한계

관련 파일:

- `experiment/config.py`: 기존 13개 조건은 `CONDITIONS`에 유지된다.
- `experiment/error_injector.py`: `apply_rotation()`은 회전된 꼭짓점을 감싸는
  axis-aligned 박스를 반환한다.
- `experiment/iou_table.csv`: 기존 조건별 평균 IoU와 IoU 감소율을 사후 계산한 표다.

핵심 한계:

1. KITTI 2D 라벨과 YOLO 일반 모델은 `(cx, cy, w, h)`만 쓰므로 각도 값을 저장하지 않는다.
2. 현재 회전 조건은 실제 OBB가 아니라 "회전 후 외접 AABB"다.
3. 그래서 `+15도`와 `-15도`는 방향이 달라도 평균 IoU가 거의 같고, 크기 확대 오류와
   통계적으로 섞일 수 있다.
4. 기존 결과는 "회전각 문제가 완전히 해결됐다"가 아니라 "축정렬 박스로 근사했을 때
   성능 저하가 관찰됐다"로 표현해야 한다.

## MVP에서 반영한 대안 조건

교수님 피드백에 따라 다음 후보 조건을 코드에 추가했다.

| 조건 유형 | 의미 | 왜 필요한가 |
|---|---|---|
| `translation_x` | 박스 중심을 가로 방향으로 이동 | 라벨 위치가 자동차 중심에서 밀린 경우를 직접 표현 |
| `translation_y` | 박스 중심을 세로 방향으로 이동 | 상하 위치 오차를 분리해서 볼 수 있음 |
| `scale` | 가로와 세로를 같은 비율로 확대/축소 | 회전 근사에서 섞였던 "박스 전체 크기 변화"를 독립 조건으로 분리 |

기존 13개 실험 결과와 충돌하지 않도록 이 조건들은 `NEXT_PHASE_CONDITIONS`에만 들어 있다.
즉, 기존 `run_all.py`와 `conditions_in_run_order()`는 지금까지와 같은 13개 조건을
실행한다. 다음 실험을 돌릴 때 명시적으로 새 조건 목록을 선택하면 된다.

## OBB 도입 시 필요한 범위

OBB를 도입하려면 단순히 함수 하나만 바꾸는 것이 아니라 데이터, 모델, 평가, 대시보드가
함께 바뀐다.

| 영역 | 필요한 변경 |
|---|---|
| 라벨 포맷 | `(class, cx, cy, w, h)`에서 각도 또는 4개 꼭짓점 포맷으로 확장 |
| 데이터셋 | KITTI 2D 라벨만으로는 부족하므로 OBB 라벨 생성/변환 규칙 필요 |
| 모델 | Ultralytics YOLO OBB 계열 등 OBB 학습을 지원하는 모델 검토 |
| 오류 주입 | `apply_rotation()`이 AABB 외접 박스가 아니라 실제 OBB를 반환해야 함 |
| 평가 | axis-aligned IoU가 아니라 rotated IoU 또는 polygon IoU 필요 |
| API/대시보드 | 각도 기반 조건, rotated IoU, 시각화 샘플을 표시할 필드 추가 |

## 비용과 리스크

| 항목 | 예상 비용 | 리스크 |
|---|---:|---|
| OBB 라벨 포맷 설계/변환 | 중간 | KITTI 원본 2D 라벨만으로 실제 각도 정답을 만들기 어려움 |
| OBB 모델 학습 파이프라인 | 중간~높음 | 현재 13개 실험과 직접 비교하려면 재학습 필요 |
| rotated IoU 평가 코드 | 중간 | 기존 IoU 표와 정의가 달라 설명이 복잡해짐 |
| 대시보드 시각화 | 낮음~중간 | 수치뿐 아니라 기울어진 박스를 보여주는 UI가 필요 |

## 후속 로드맵

1. **현재 MVP 유지**: 기존 13개 결과, PDF 보고서, 대시보드는 보존한다.
2. **대안 조건 실험**: `translation_x`, `translation_y`, `scale` 조건으로 2차 실험을
   돌려 회전 근사의 한계를 보완한다.
3. **IoU 기준 재정렬**: magnitude 대신 평균 IoU 감소율이 비슷한 조건끼리 비교한다.
4. **OBB 파일럿**: 소규모 샘플에서 OBB 모델과 rotated IoU를 검증한다.
5. **본선형 확장**: OBB 결과가 기존 AABB 결과보다 오류 유형 분리력이 높을 때만 전체
   파이프라인 교체를 진행한다.

## 발표용 표현

권장 표현:

> 현재 MVP는 KITTI 2D 라벨 구조 때문에 회전각을 OBB로 직접 학습하지는 않았습니다.
> 기존 회전 조건은 축정렬 박스 근사 실험으로 보존하고, 교수님 피드백을 반영해 중심점
> 이동과 스케일 조건을 다음 실험 후보로 코드에 추가했습니다. OBB는 본선 단계에서
> 별도 파일럿으로 도입 범위와 비용을 검증하겠습니다.

피해야 할 표현:

> 회전각 오류 문제를 완전히 해결했습니다.

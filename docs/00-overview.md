# 00. 프로젝트 개요

## 무엇을 만드는가

**AIDA (AI Data Assurance)** — 객체탐지 AI 학습데이터의 바운딩박스 라벨 오류를
자동 진단하고 품질을 인증하는 B2B 데이터 품질검증 플랫폼.

## 왜 만드는가 (문제)

- 객체탐지 AI는 바운딩박스 라벨을 기준으로 학습하므로, 라벨 오류가 있으면 모델
  성능이 저하된다.
- 그런데 지금은 모델 성능이 낮을 때 "모델 자체 문제인지, 학습데이터 라벨 오류인지"를
  객관적으로 구분할 방법이 없다.
- 기존 수작업 검수·단순 형식 검증은 "라벨이 형식적으로 맞는가"만 확인할 뿐,
  "그 오류가 실제 AI 성능에 얼마나 영향을 미치는지"는 진단하지 못한다.

## 어떻게 푸는가 (해결)

국방과학연구소 특허 「가상 이미지 데이터 기반의 학습 데이터 검증 장치 및 방법」
(등록번호 10-2664201)의 방법론을 민간 AI 데이터 품질검증에 적용한다.

1. 참값(GT) 바운딩박스에 크기(가로/세로)·회전각을 통제적으로 변형한 "에러 바운딩박스"를 생성
2. 이 에러 라벨로 학습한 모델과 정상 라벨로 학습한 모델의 성능 차이를 측정해
   "오류 유형별 성능 저하 패턴"을 구축
3. 실제 고객 데이터셋의 성능을 이 패턴과 비교해, 어떤 유형의 라벨 오류가 존재할
   가능성이 높은지 역으로 진단

자세한 기술 원리는 [01-technology.md](./01-technology.md) 참고.

## 누가 쓰는가 (고객)

1차: 자율주행·모빌리티 비전 AI 기업, 완성차·부품사 (데이터 발주처)
2차: 공공 AI 데이터 구축기관, 스마트팩토리, CCTV 영상분석 기업
3차: 데이터 라벨링·구축 업체 (발주처 납품 요건 충족용 사전 QA 도구)

## 지금 하고 있는 것 (2026-07 시점)

- 2026 국방기술을 활용한 창업경진대회 학생부 1차 서류심사 통과, 2차 예선(캠프형 평가) 준비 중
- 기술 검증 실험(YOLOv8 기반, KITTI Car 클래스, 7개 오류 조건) 설계 완료, 실행 예정
- MVP 웹 대시보드(FastAPI + React/TypeScript) 스캐폴딩 완료

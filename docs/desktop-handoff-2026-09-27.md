# 데스크탑 인수인계 — 노트북 준비 완료, 본 평가 미시작

> **2026-10-01 추가 인수인계:** 통제 실험 기준선은 [조사 문서 6절](paper/controlled-baseline-audit.md)의 읽기 전용 목록 확인부터 진행한다. 기존 가중치 재추론과 재학습을 구별한다. 아래 내용은 작성 당시 기록이다.

## 현재 경계

이 작업은 노트북에서 코드·문서와 합성 검사를 준비한 것이다. 실제 가중치·train 이미지·val·보호 자료는 열지 않았다. 사전 등록은 미확정이다. (a) 고정 재표본 합집합 방식은 구현돼 있으나 최종 채택, 판정 상한 C, 모델 식별자와 프롬프트는 사용자 확인이 남아 있다.

## 이번 수정

- AI 입력은 같은 표시 규칙의 전체 장면과 대상 크롭 두 파일을 제공한다. manifest의 `full_file`과 `file`을 둘 다 첨부한다.
- 라이브러리 호출에서도 점수·방법·기존 판정이 있는 입력을 거부한다. 새 보조 queue의 `verdict=null`은 허용한다.
- 분석은 고정 재표본뿐 아니라 원래 상위 N의 미판정도 거부한다. hold는 완료 판정이다.
- 프롬프트의 가시성 20% 예외를 복원했다. 3회 반복·후보별 새 대화·온도 0은 자동 확정하지 않는다. 실제 환경이 제공하지 않는 설정은 미노출로 기록한다.

## 데스크탑에서 이어서 할 일

1. 저장소에서 `git status --short`를 확인하고 미커밋 변경을 보존한다. `git pull --ff-only`로 받는다. 충돌 시 덮어쓰지 않는다.
2. 아래 명령을 **AIDA 루트**에서 실행한다. Python 환경이 없으면 이름을 추측해 대체하지 말고 실제 경로를 확인한다.

```powershell
& .\experiment\venv\Scripts\python.exe .\experiment\check_run_environment.py --out .\experiment\planning_evidence\desktop_environment.json
```

가중치 exists=true, SHA-256, cleanlab·ultralytics·torch 버전과 commit을 확인한다. 값이 null이면 연습 추론으로 넘어가지 않는다. SHA와 cleanlab 버전은 사전 등록 전에 기록할 수 있고, 본 실행 기록에서 다시 대조한다. 환경 JSON은 사용자 로컬 경로를 점검한 뒤 필요한 정보만 문서에 옮긴다.

3. [연습 계획](practice-judging-plan.md)에 따라 **train fit_check임을 먼저 확인**하고 별도 연습 ID로 업로드·진단한다. backend 서버는 backend 환경, 추론은 experiment 환경이다. 대용량 다운로드·학습은 필요 없다. 무거운 작업을 새로 해야 하면 예상 시간·용량부터 사용자에게 알린다.
4. 판정 입력은 전체 장면 + 크롭 모두 확인한다. 전체 이미지에서 대상과 다른 라벨이 보이는지, 크롭 좌표가 원본 기준인지 확인한다. 브라우저 판정 화면의 실제 렌더링·저장도 데스크탑에서 점검한다.
5. 사용자가 20~60건을 hit/miss/hold로 연습한다. 애매한 사례와 실제 시간을 기록한다. 연습 결과는 본 분석에 넣지 않으며 AI 일치율 합격선을 만들지 않는다.
6. [AI 프롬프트 초안](ai-adjudicator-prompt-draft.md)을 연습 지침과 맞춘다. 모델·입력 해상도·세션 단위·반복 횟수·응답 선택 규칙을 확정한다. 유료 호출은 비용 상한과 사용자 확인 없이 시작하지 않는다.
7. 사용자가 (a) 최종 채택과 C를 정한다. C는 사람이 판정할 고유 후보 총수이며 비교 예산 N=90 및 AI 호출 횟수와 별개다. 추가 후보를 판정해도 원래 상위 N은 바뀌지 않는다.
8. 여기까지 결과를 보고한다. 빈칸 없는 사전 등록의 검토·커밋 전에는 val을 열지 않는다. 이번 인수인계의 즉시 목표는 **환경 확인과 train 연습 준비**다.

## 본 평가로 넘어갈 때만 사용할 분석 경로

사전 등록 이후 목록을 고정하고 판정을 모두 마친 뒤에만 실행한다. 본 평가 값을 여기서 임의 확정하지 않는다.

```powershell
& .\experiment\venv\Scripts\python.exe .\experiment\analyze_qa.py --export labelled_primary.json --budget 90 --iterations 2000 --seed 42 --methods aida all_label_iou all_label_objectlab --adjudicator primary --out qa_result.json
```

묶음 설정·입력 지문 불일치 또는 원래/재표본 상위 N 미판정 시 중단한다. AI 보조 30% 원본으로 사람 전량 분석을 대체하지 않는다. 민감도 분석은 별도 파생 판정 원본과 변환 규칙을 보존해 준비해야 하며 자동 구현 완료로 간주하지 않는다.

## 데스크탑에 남은 검증

실제 자 해시·실제 추론, frontend 검사와 브라우저 동작, 실제 장면에서의 원본/크롭 시각 점검, 사람 연습, AI 호출은 노트북에서 검증하지 않았다. 고정 재표본의 판정 누락 방지는 신뢰구간 포함률 보장이 아니다.

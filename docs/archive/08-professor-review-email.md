## 메일 본문

김성호 교수님께

안녕하십니까, 교수님.

바쁘신 중에도 메일로 검토해 주시겠다고 답신해 주셔서 진심으로 감사드립니다.

저희가 준비 중인 AIDA는 객체탐지 AI 학습데이터의 바운딩박스 라벨 오류를 진단하는
품질검증 플랫폼입니다. 공개 데이터셋(KITTI Car 클래스)의 참값 바운딩박스에
가로·세로 길이, 회전각 오류를 통제적으로 주입하고(±15%/±30%, ±7.5°/±15°, 총 13개
조건), 오류 유형별 객체탐지 모델의 성능 저하 패턴을 구축한 뒤 실제 데이터셋의
성능과 비교하여 오류 유형을 추정하는 방식을 구상하고 있습니다.

교수님께서는 아래 사항을 중심으로 검토해 주시면 감사하겠습니다.

1. 오류 유형별 모델 성능 저하 패턴을 비교하여 실제 데이터셋의 라벨 오류 유형을
   추정하는 접근이 기술적으로 타당한지, 서로 다른 오류 유형이 유사한 성능 저하를
   보여 역진단이 어려워질 가능성은 없는지
2. KITTI의 일반적인 2D 바운딩박스는 축정렬 방식인데, 회전각 오류를 초기 실험에
   포함하는 것이 적절한지, 혹은 중심점 이동으로 대체하는 것이 더 현실적인지
3. mAP@0.5, mAP@0.5:0.95, Precision, Recall을 하나의 성능 벡터로 만들어 정규화 후
   거리(유클리드/코사인)로 오류 패턴을 비교하려 하는데, 이 방식이 타당한지, 혹은
   통계적 검정이나 분류 모델을 쓰는 것이 더 적절한지
4. 2차 예선에서 기술 가능성을 보여주기 위한 최소 성공 기준과, 심사위원에게 가장
   설득력 있는 실험 결과·시각화가 무엇일지
5. 현재 설명이 실제 구현 가능성 있는 아이템으로 설득력 있게 들리는지, 성능 결과만으로
   라벨 오류를 역추정한다는 부분에 논리적 비약이 있다면 솔직한 의견 부탁드립니다

검토에 필요한 아이템 개요, 기술 흐름, 실험 조건(13개)과 세부 배경을 정리한 자료를
첨부드립니다. 아직 초기 단계의 구상이라 부족한 점이 많지만, 교수님의 의견을
바탕으로 기술 범위와 실험 설계를 구체화하고자 합니다.

바쁘신 가운데 귀한 시간을 내어 검토해 주셔서 다시 한번 감사드립니다.

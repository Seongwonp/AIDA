# 18. AIDA 2차 예선 발표자료 제작 가이드 (슬라이드 5, 6, 10번 전용)
<!-- 시점 표시 -->

> **끝난 일의 기록이다.** 2026 국방기술 창업경진대회는 2026-08-19에 2차 예선에서 탈락했고, 그 뒤로 프로젝트는 발표 준비가 아니라 기술 검증으로 방향을 바꿨다. 이 문서는 **당시 상태 그대로 두며 갱신하지 않는다** — 지금 시스템과 다른 것이 정상이다. 현재 상태는 저장소 README와 [21-next-plan.md](./21-next-plan.md)를 볼 것.


본 문서는 실측 실험 완료 후, 발표자료 PPT의 핵심 슬라이드인 **5번(기술 원리/MVP), 6번(결과물), 10번(리스크 대응)**에 바로 적용할 수 있는 텍스트, 시각 자료(그래프/다이어그램), 발표 대본(스크립트) 가이드입니다.

## 5번 슬라이드: 기술 원리 / MVP

### 1. 슬라이드 구성 내용
* **핵심 메시지**: "특허 기술 기반의 통제된 오류 주입 및 AI 모델 파이프라인 설계 완료"
* **주요 항목**:
  * **대상 데이터**: KITTI 자율주행 데이터셋에서 Car 클래스 520장 고정 분할 추출 (학습 400장, 평가 120장)
  * **비교 모델**: COCO 사전학습 가중치를 활용해 학습 가중치를 균일하게 파인튜닝한 YOLOv8n 모델 사용
  * **오류 주입 알고리즘**: 원본 참값(GT) 중 30%를 무작위 선택하여 6가지 수학적 변형 적용
    * *크기 오류*: 가로/세로 길이 변형 (중심 고정)
    * *회전 오류*: 중심 기준 회전 후 축정렬 박스(AABB) 재계산 근사
    * *중심점 이동 (Translation)*: 박스 크기는 유지하고 가로/세로 방향 오프셋 이동 (**교수님 피드백 반영**)
    * *스케일 (Scale)*: 가로와 세로를 동일 비율로 확대/축소 (**교수님 피드백 반영**)
  * **성능 패턴 DB**: 동일 조건(50 epoch) 하에 21개 모델을 학습 및 평가하여 metrics 구축

### 2. 들어갈 시각 자료 (다이어그램)
* **'에러 바운딩 박스 변형' 3단 다이어그램**:
  * `[정상 (Clean)]`: 객체 중심에 정확히 맞는 2D 바운딩박스.
  * `[중심점 이동 (Translation)]`: 크기는 같지만 한쪽으로 밀린 박스 (위치 오차).
  * `[스케일 (Scale)]`: 중심은 같지만 전체 비율이 확대/축소된 박스 (크기 오차).
  * `[회전각 근사 (Rotation)]`: 회전 후 수평/수직으로 늘어나 외접하는 축정렬 박스 (근사 오차의 한계 시각화).

### 3. 발표 대본 (Script)
> "5번 슬라이드, 기술 원리와 MVP 구현 상태입니다. 저희는 국방과학연구소 특허의 핵심 원리를 민간 객체탐지 데이터에 최적화하여 구현했습니다. 신뢰도 높은 KITTI 자율주행 데이터셋을 활용하고, COCO 사전학습된 YOLOv8n 모델을 사용해 학습 조건을 균일하게 통제했습니다. 
> 
> 특히, 김성호 교수님의 기술 조언을 적극 수용하여 기존의 가로/세로 크기 및 회전 오류뿐만 아니라, **바운딩 박스 중심점 이동(Translation)과 스케일(Scale) 오류**를 대안 조건으로 추가해 총 21가지 에러 매트릭스를 완성했습니다. 각 조건별로 참값(GT)과 에러 박스의 실제 겹침도인 **IoU 감소율**을 산출하여 오류 강도를 객관화하고 성능 저하 패턴 DB를 성공적으로 구축 완료했습니다."

## 6번 슬라이드: 결과물 (Deliverables)

### 1. 슬라이드 구성 내용
* **핵심 메시지**: "실측 결과 증명: 바운딩 박스 위치 오류가 단순 크기 오차보다 모델 성능에 더 심각한 영향을 준다"
* **실험 결과 요약**:
  * **가장 해로운 오류**: `rot_m15`(회전 15도 외접 근사) 조건에서 **-5.7%**의 가장 큰 mAP 저하 관찰.
  * **위치 편차(Translation)의 파괴력**: 박스 크기는 유지하고 중심점만 15% 가로 이동시킨 `trans_x_m15`에서 mAP 저하율 **-2.4%** 기록. 이는 단순 가로/세로 크기 오차의 최대 저하폭(-1.5%~-2.4%)을 상회하여, **YOLO 모델이 크기 변화보다 박스의 위치가 어긋나는 오차에 훨씬 더 민감함**을 입증.
  * **스케일 축소의 한계**: 스케일 30% 축소 조건(`scale_m30`)에서 IoU가 0.49까지 떨어지며 급격한 성능 저하 관찰.
* **대시보드 주요 기능 스크린샷 연계**:
  * **품질 인증서 발급 예시**: 78점 판정 및 "미인증(UNCLASSIFIED)" 리포트 시각화.
  * **ROI 정량화 수치**: 수작업 검수 범위 70% 축소 및 재학습 예방을 통해 프로젝트당 **777만 원의 절감 가치** 시각화.

### 2. 들어갈 시각 자료 (그래프 및 표)
* **그래프**: `docs/assets/experiment-results-full21.png` 이미지 첨부 (21개 에러 조건별 성능 저하 막대그래프).
* **표**: [17-professor-feedback-response.md](./17-professor-feedback-response.md) 문서의 **3장 통합 실험 결과표**에서 핵심 조건(clean, rot_m15, trans_x_m15, scale_m30 등) 위주로 축약한 요약 표 구성.

### 3. 발표 대본 (Script)
> "6번 슬라이드는 실제 21개 에러 조건의 실측 실험 결과와 대시보드 화면입니다. 실험 결과, 네모 박스가 회전하거나 찌그러지는 왜곡 조건이 가장 치명적인 성능 하락을 일으켰습니다. 
>
> 특히 이번에 도입한 **중심점 이동 조건(trans_x_m15)은 크기가 30% 증가/감소한 오류보다 성능을 더 많이 하락**시켜, 인공지능이 '위치 정렬 오차'에 취약함을 데이터로 증명했습니다. 
> 
> 대시보드에서는 이 실측 패턴을 기반으로 고객 데이터셋의 오류 유형을 확률적으로 분류하고, 성능 하락을 유발하는 **의심 라벨 상위 30%를 우선 검수 가이드**로 제시합니다. 이를 통해 수작업 재검수 인건비를 70% 아끼고 무의미한 재학습 GPU 비용을 세이브하여, 단일 프로젝트 기준으로 약 **777만 원의 구체적인 비용 절감 효과(ROI)**를 발주처에 즉시 제공합니다."

## 10번 슬라이드: 리스크 대응 (Risk Response)

### 1. 슬라이드 구성 내용
* **핵심 메시지**: "기술적/학술적 한계의 선제적 인정 및 확실한 후속 로드맵 제시"
* **대응 논리**:
  * **2D 축정렬 박스의 기하학적 한계**: 일반 YOLO 모델에서는 기울어진 라벨링을 직접 학습할 수 없어 외접 박스로 근사하는 한계가 있음.
  * **OBB(Oriented Bounding Box) 후속 로드맵**: 본선 단계에서는 YOLO OBB 계열 모델을 도입하고 Rotated IoU 평가지표를 연동하는 로드맵 확립.
  * **비적격 문제(Ill-posed Problem) 대응**: 데이터 오류 100% 역추정의 한계를 인정하고, '확정 판정'이 아닌 **'검수 우선순위(Priority Rating) 필터링 가이드'**로 비즈니스 가치를 재포지셔닝하여 논리적 방어막 구축.

### 2. 발표 대본 (Script)
> "마지막으로 10번 슬라이드, 리스크 대응과 향후 계획입니다. 저희 플랫폼은 현재 KITTI 2D AABB 포맷의 한계로 인해 회전 오류를 축정렬 외접 박스로 근사하여 평가하는 한계가 있습니다. 
> 
> 이를 극복하기 위해 본선 진출 시 **기울어진 라벨을 직접 학습하는 OBB 모델과 Rotated IoU를 도입하는 데이터 변환 로드맵**을 완비하여 기술적 설득력을 확보했습니다. 
> 
> 또한, 라벨의 오류를 역추정하는 비적격 문제를 방어하기 위해 '완벽한 진단' 대신 **'재검수 우선순위를 좁혀주는 가이드라인'**으로 포지셔닝하여 발주처의 예산 절감 효과(ROI)를 극대화하는 방향으로 사업 타당성을 확보해 나가겠습니다. 감사합니다."

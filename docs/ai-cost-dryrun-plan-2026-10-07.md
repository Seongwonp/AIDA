# AI 보조 판정자 비용 드라이런 — 설계만 (2026-10-07, 실행하지 않음)

> **실행하지 않았다.** 이 문서는 설계다. 이미지를 외부로 한 장도 보내지 않았고 API를 한 번도 부르지 않았다.
> 실행하려면 **사용자의 별도 승인**이 필요하다 — 1절의 외부 전송 문제를 사용자가 먼저 정하고, 그다음 2절의 범위·상한을 승인한다.
> 사전 등록 5-4절(AI 보조 판정자 실행 명세)의 실행 전 기입 칸을 채우는 것이 목적이다.

## 1. 먼저 정할 것 — nuImages 이미지를 제3자 API로 보내도 되는가 (사용자 결정)

**이것은 법적 판단이 아니다.** 아래는 내려받은 메타데이터에 들어 있는 약관 파일(`D:/AIDA-eval/nuimages/all/LICENSE`,
"nuScenes, nuPlan, nuImages, and nuReality Terms of Use", 파일 안 표기 "last updated on Nov 16, 2021")에서 외부 전송·공유와
닿는 부분을 찾아 짧게 인용·요약한 것이다. 해석과 결정은 사용자가 한다.

| 약관 위치 | 짧은 인용 | 요약 |
|---|---|---|
| Terms of Use — Licenses | "provided to You under a Creative Commons Attribution-NonCommercial-ShareAlike 4.0" | 데이터셋은 CC BY-NC-SA 4.0에 추가 조건을 더해 제공된다. 둘이 충돌하면 추가 조건(Dataset Terms)이 우선한다 |
| Terms of Use — 첫 머리 | "available for non-commercial use" | 비상업 용도에 한해 제공된다 |
| Terms of Use — Exceptions for some third-party data | "may not be redistributed or reused without the consent" | 일부 제3자 제공 자료는 원 제공자 동의 없이 재배포·재사용할 수 없을 수 있고, 해당 조건은 메타데이터에 들어 있다고 적혀 있다. 우리가 쓰는 Car 이미지에 그런 표시가 있는지는 확인하지 않았다 |
| Terms of Use — 마지막 단락 | "solely Your responsibility to comply with all applicable laws" | 개인정보·데이터 보호 등 관련 법 준수는 사용자 책임이다. 주행 이미지에는 보행자·번호판 등이 찍혀 있을 수 있다 |
| CC BY-NC-SA 4.0 Section 1(l) "Share" | "provide material to the public by any means" | 라이선스의 "Share"는 **공중에** 제공하는 것으로 정의된다. 특정 API 제공자에게 처리를 맡기는 전송이 이것에 해당하는지는 약관에 직접 적혀 있지 않다 |
| CC BY-NC-SA 4.0 Section 2(a)(1) | "for NonCommercial purposes only" | 복제·공유는 비상업 목적에 한한다 |

**약관에 "제3자 API·클라우드 처리 서비스로 보내는 것"을 직접 허용하거나 금지하는 문장은 찾지 못했다.** 따라서 이 문서는 결론을
내지 않는다. 사용자가 정할 것:

1. nuImages 이미지(train 연습 후보, 나중에는 val 보조 표본)를 제3자 API 제공자에게 보내는 것을 받아들이는가.
2. 받아들인다면, 제공자의 데이터 보존·학습 사용 조건을 실행 직전에 확인해 실행 기록에 적는가(이 문서는 제공자 약관을 읽지 않았다).
3. 받아들이지 않는다면 AI 보조 판정(D8)은 "미실행"으로 실행 기록에 남기고 1차 분석은 바뀌지 않는다(D8: 1차는 사람 판정 원본).

## 2. 드라이런 범위 (승인되면)

| 항목 | 값 |
|---|---|
| 후보 | **train fit_check의 연습 후보(practice1)에서 최대 20건.** val 후보·본 평가 후보는 **절대 쓰지 않는다**(val은 사전 등록 확정 커밋 전까지 열지도 않는다) |
| 뽑는 법 | 연습 묶음의 가림 목록(`GET .../queue?adjudicator=ai`)에서 기존 라벨·누락을 섞어 고정 씨앗으로 20건. 씨앗은 본 판정 씨앗(20260927~20260930, 42)과 다르게 하고 실행 기록에 적는다 |
| 그림 | `render_adjudication_images.py` 기본값(사전 등록 5-4절과 같다) — 전체 장면 + 크롭 |
| 프롬프트 | 사전 등록 5-4절의 지문과 같은 블록(`ai_adjudicator.py --prompt-from-draft --expected-prompt-sha256 20d40b44…`) |
| 모델 | `claude-sonnet-5` 그대로(별칭 없음) |
| 비용 상한 | 드라이런 자체에도 `CostGuard`를 건다. 상한은 사용자가 승인 때 정한다(코드 최대 $10, 인자로 낮추기만 가능) |
| 호출 수 | 후보당 1회, 새 대화 — 최대 20회 |

## 3. 재는 것

- 호출마다 응답의 **실제 사용량**: 입력 토큰, 출력 토큰(응답 객체의 사용량 필드 그대로).
- 실행 시점에 읽은 **공개 단가**(문서 주소·읽은 시각·값)로 계산한 호출당 비용.
- 응답에 적힌 모델 식별자, 사용한 SDK·API 버전 문자열, 온도를 설정할 수 있었는지(거부되면 "설정 불가").
- 실제 전송한 그림의 픽셀 크기와 바이트 SHA-256, 제공자 쪽 축소가 있었는지(문서·사용량으로 확인되는 만큼만).
- 시간 초과·전송 오류 횟수(재시도 수·시간 제한을 정하는 근거).
- 형식 위반·거부 수(분석에 쓰지 않는다 — 프롬프트 점검용).

## 4. 1,000건 상한으로 외삽

- 본 판정의 AI 보조 표본은 확장된 최종 판정 목록의 30%(올림)다. 판정 상한 C=1,000이면 **AI 호출은 최대 300회**다(반복 1회).
- 예상 비용 = 300 × (드라이런 호출당 입력 토큰의 **최댓값** × 입력 단가 + `max_tokens` × 출력 단가) / 100만. 평균이 아니라 최댓값과
  출력 상한으로 잡는다 — 그림 크기가 후보마다 달라 입력 토큰이 흔들린다.
- 이 예상이 $10을 넘으면 본 실행을 시작하지 않는다(`CostGuard.preflight`). 그때는 그림 해상도·반복 수 등 무엇을 바꿀지를 사전 등록
  확정 **전에** 사용자가 정한다.
- 20건에서 낸 수치는 **계획용**이다. 결과·일치도로 쓰지 않는다.

## 5. 드라이런이 채우는 사전 등록 칸 (5-4절·11절)

API 버전·SDK 버전, 온도 설정 가능 여부, 실제 전송 해상도, 재시도 최대 횟수, 호출당 시간 제한. 사람 판정 지침 부록은 이 드라이런과 무관하다.

## 6. 하지 않는 것

- val·본 평가 후보를 보내지 않는다. 연습 판정(practice1)의 사람 판정을 AI 입력에 넣지 않는다(가림 목록만).
- 응답을 보고 프롬프트를 고치면 프롬프트 지문이 바뀐다 — 그때는 사전 등록 5-4절의 지문을 고쳐 다시 커밋한 뒤에만 본 실행을 한다.
- `--provider`는 아직 구현되어 있지 않다(`NotImplementedError`). 승인 뒤 구현할 때 `CostGuard`를 호출 경로 앞에 둔다.

# AI 보조 판정자 프롬프트 — 초안 (2026-09-27, 확정 아님)

> **모델 식별자는 비워 둔다.** 임의로 채우지 않는다. 연습(train fit_check)에서 입력 형식을 점검한 뒤 확정본에
> 원문 그대로 고정한다. 근거는 [`literature-review-2026-09-27.md`](literature-review-2026-09-27.md) §2
> (그림 표시가 좌표보다 낫다, amodal 규칙을 명시, 선택지 순서 고정, 원문 응답 보존, 온도 0, 거부는 hold).

## 실행 명세 (확정본에 채울 것)

| 항목 | 값 |
|---|---|
| 모델 식별자·버전·스냅샷 날짜 | **[미정 — 임의로 채우지 않는다]** |
| 온도 / 추론 모드 / 입력 해상도 | 0 / [미정] / 원본 crop 그대로 |
| 반복 | 같은 입력 3회, 다수결이 아니라 **첫 응답을 판정**으로 쓰고 세 응답의 일치 여부를 기록 |
| 입력 | `render_adjudication_images.py`가 만든 그림 1장 + 아래 텍스트. **점수·순위·방법·출처·사람 판정 없음** |
| 세션 | 후보마다 **새 대화**. 이 설계 대화·다른 판정을 전달하지 않는다 |
| 응답 저장 | 원문 전체를 `ai_responses/<후보 id>.json`에. 거부·회피·형식 위반 → `hold`로 사상하고 원문 보존 |
| 표본 | 묶음의 `auxiliary_sample.candidate_ids`(확장된 최종 목록에서 추출) |

## 시스템 프롬프트 (초안)

```
당신은 자율주행 주행 이미지의 객체 탐지 라벨을 검수합니다. 한 장의 그림과 상자 좌표를 받고, 정해진 세 답 중 하나만 냅니다.

라벨 규칙 (nuImages):
- 차량(Car)에는 승용차·왜건·밴·미니밴·SUV·지프가 들어갑니다. 화물용 픽업은 아닙니다.
- 상자는 가려진 부분까지 추정해 객체 전체를 감쌉니다(amodal). 이미지 가장자리에서 잘린 객체는 가장자리에서 멈춥니다.
- 사이드미러·안테나는 상자에 넣지 않습니다.
- 높이 10px 미만이거나 20% 미만만 보이는 객체는 라벨을 달지 않는 것이 규칙입니다.

그림 규칙:
- 빨강 실선 = 지금 판정하는 기존 라벨. 빨강 점선 = 라벨이 빠졌다고 지목된 자리. 파랑 = 이 이미지에 이미 있는 다른 라벨.

판단 기준:
- 기존 라벨(빨강 실선): "이 라벨을 이대로 학습에 써도 되는가, 고쳐야 하는가."
  hit = 고쳐야 한다(명백히 넘치거나 모자라거나 밀렸거나 다른 것을 감쌌다).
  miss = 이대로 써도 된다(몇 픽셀 차이는 고칠 필요 없음).
  hold = 경계가 애매하거나 가림·크기 때문에 확인할 수 없다.
- 누락 자리(빨강 점선): "이 자리에 라벨돼야 할 차량이 있는가."
  hit = 실제 차량이 있는데 파랑 라벨이 없다.
  miss = 차량이 아니거나 라벨 대상이 아니거나 이미 파랑 상자가 덮고 있다.
  hold = 가림·해상도 때문에 확인할 수 없다.

억지로 정하지 마십시오. 망설여지면 hold입니다. 답은 다음 JSON 한 줄만 냅니다:
{"verdict": "hit" | "miss" | "hold", "reason": "<한 문장>"}
```

## 사용자 메시지 (후보마다)

```
[그림 첨부]
과제: {labelled → "기존 라벨 검수" | missing → "누락 검수"}
클래스: {class_name}
상자(원본 픽셀, x1 y1 x2 y2): {box}   원본 크기: {w}×{h}
답: {"verdict": ..., "reason": ...}
```

선택지 순서(hit, miss, hold)는 고정하고 바꾸지 않는다. 유도 표현("이 상자는 틀린 것 같지 않습니까")을 넣지 않는다.

## 일치도의 뜻

보조 표본은 확장된 최종 판정 목록(원래 상위 N ∪ K ∪ 재표본 추가 후보)에서 뽑는다. 일치도는 그 목록 전체에서의
사람–AI 일치를 대표하며, 원래 상위 N만의 일치도가 아니다. 낮아도 "AI가 틀렸다"고도 "사람이 틀렸다"고도 말하지
않는다. 1차 분석은 사람 판정 원본이며 불일치로 수정하지 않는다.

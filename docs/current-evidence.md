## 9. 화면의 ROI 추정 — 관측이 아니다

| | |
|---|---|
| **성격** | **계산식이다.** 라벨 수 × 건당 검수 시간 ÷ 60 × 시간당 인건비 |
| **상태** | **현재 미검증** — 실제 절감을 관측한 적이 없다 |
| **근거** | 없음. 입력값(검수 시간·인건비·재학습 횟수)은 **가정**이다 |
| **화면 표기** | 계산식과 가정을 카드 안에 적어 둔다 |

# 07. 사업화 로드맵

사업계획서(AIDA_사업계획서.pdf) 기준 정리.

## 제품·서비스 성장 단계

```
01. 기술검증기    자체/공개 데이터셋 활용, 바운딩박스 오류 진단 엔진 및 품질 리포트 표준양식 구축
02. 초기시장 진입기  AI 개발사·비전 AI 기업 대상 샘플 리포트·소규모 PoC 제공, 고객 레퍼런스 확보
03. 성장기        공공 AI 데이터구축기관, 스마트팩토리, CCTV 영상분석 기업으로 고객군 확대
04. 확장기        데이터 라벨링·구축 기업이 발주처 요구에 따라 AIDA 검증 리포트를 발급받는 구조로 확장
```

## 사업화 추진 일정

| 시기 | 내용 |
|---|---|
| 2026 Q3 | 특허 기반 핵심 엔진 구현 (가상 에러 데이터셋 생성 + 성능 비교 모듈) |
| 2026 Q4 | 품질 검증 플랫폼 베타 론칭, 2차 특허(10-2701172) 파이프라인 연동 |
| 2027 Q1 | 자율주행 샘플 데이터셋 분석, PoC 확보 |
| 2027 Q2~ | 유료 전환 및 인증서 발급, 건수형 과금 → API 구독 모델 순차 전환 |

## 고객 확보 4단계

```
01. 발주처 인터뷰   → 라벨 오류 경험·검수 부담·제3자 리포트 필요성 확인
02. 샘플 데이터셋 진단 → 오류 유형 분석 결과가 고객 기존 검수 결과와 일치하는지 검증
03. PoC 진행        → 실제 데이터셋 전수 검증, 채택 여부 결정
04. 유료 전환 검토   → 지불 의사, LOI/MOU 체결 여부 확인
```

## 비즈니스 모델 요약

- **초기 수익**: 데이터셋 건수 기반 검증·인증 리포트 과금 (모델 재학습 1회 비용보다 낮은 단가)
- **확장 수익**: 품질 리포트·인증서 발급 별도 수수료, API 이용 계약, 프로젝트 단위 검수 계약
- **장기 수익**: 웹 기반 플랫폼 API 연동형 사용량 기반 과금

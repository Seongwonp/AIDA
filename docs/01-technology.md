> 보강을 위한 **보조 유형**으로 구분해서 다룬다.

## 4단계 기술 원리

```
01. 가상 이미지와 참값 생성   → 공개 데이터셋 이미지 + 원본 라벨을 참값(GT)으로 채택
02. 에러 바운딩박스 생성      → 참값에 가로/세로/회전각 오류를 통제적으로 주입
03. 모델 학습과 평가 자동화   → 에러 라벨 vs 정상 라벨로 각각 학습, 성능 자동 비교
04. 오류 판단                 → 성능 저하 패턴 DB와 실제 데이터 성능을 비교해 오류 유형 역추정
```

1~3단계는 "레퍼런스(성능 저하 패턴 DB)를 만드는 과정"이고, 4단계가 실제 서비스가
파는 가치(진단)다. 1~3은 4를 가능하게 만드는 내부 엔진이다.

## 왜 "가상 이미지"인가 (오해 방지)

특허 명세서 [0032]는 "가상 이미지 데이터 생성부는 포토샵 등의 이미지 편집
프로그램을 이용하여 가상 이미지 데이터를 생성할 수 있다"고 기술한다. 즉 특허가
말하는 "가상"의 핵심은 "실사진이 아님"이 아니라 **"참값(GT)을 정확히 알고 있는
이미지"**라는 뜻이다 ([0034]: "픽셀 정보를 기반으로 생성되므로 매우 정확한
레이블이 된다").

→ MVP 단계에서는 3D 렌더링·합성 이미지를 새로 만들 필요가 없다. 공개 데이터셋
(KITTI)의 기존 정확한 라벨을 "참값"으로 그대로 재활용하고, 거기에 오류를 주입하는
방식으로 특허의 방법론을 그대로 구현할 수 있다. 실제 이미지 합성/생성 기술은
사업화 로드맵상 후속 단계다 ([07-roadmap.md](./07-roadmap.md) 참고).

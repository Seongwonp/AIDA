# 05. 용어 사전

객체탐지/데이터 라벨링 도메인 배경지식이 없어도 이 프로젝트를 이해할 수 있도록
정리한 용어집이다.

| 용어 | 설명 |
|---|---|
| 바운딩박스 (Bounding Box) | 이미지 안에서 객체(차량, 보행자 등)의 위치를 표시하는 직사각형 라벨. 보통 (중심x, 중심y, 너비, 높이) 또는 (좌상단x, 좌상단y, 우하단x, 우하단y)로 표현 |
| 참값 (Ground Truth, GT) | 정답으로 취급되는 정확한 라벨. AIDA에서는 공개 데이터셋의 원본 라벨을 참값으로 사용 |
| 오프셋 (Offset) | 참값 바운딩박스에서 얼마나 벗어났는지를 나타내는 변형 정보 (크기·위치·회전 등) |
| 에러 바운딩박스 | 참값에 오프셋(오류)을 의도적으로 적용해 만든, 정답이 아닌 바운딩박스 |
| 객체탐지 (Object Detection) | 이미지에서 객체의 위치(바운딩박스)와 종류(클래스)를 찾아내는 컴퓨터비전 과제 |
| mAP (mean Average Precision) | 객체탐지 모델 성능을 나타내는 대표 지표. 값이 높을수록 성능이 좋음 |
| mAP@0.5 | IoU 0.5 이상을 "맞은 것"으로 간주하고 계산한 mAP (비교적 관대한 기준) |
| mAP@0.5:0.95 | IoU 0.5~0.95 구간을 세분화해서 평균한 mAP (더 엄격한 기준, COCO 표준) |
| IoU (Intersection over Union) | 예측 박스와 정답 박스가 얼마나 겹치는지 나타내는 비율 (0~1). 겹칠수록 1에 가까움 |
| Precision (정밀도) | 모델이 "객체가 있다"고 예측한 것 중 실제로 맞은 비율. 낮으면 오탐(false positive)이 많다는 뜻 |
| Recall (재현율) | 실제 존재하는 객체 중 모델이 찾아낸 비율. 낮으면 놓친 객체(false negative)가 많다는 뜻 |
| YOLO | 실시간 객체탐지에 널리 쓰이는 딥러닝 모델 계열 (You Only Look Once). AIDA는 경량 버전인 YOLOv8n 사용 |
| 파인튜닝 (Fine-tuning) | 이미 학습된(pretrained) 모델을 새 데이터로 추가 학습시키는 것. 처음부터 학습(from scratch)하는 것보다 훨씬 빠름 |
| KITTI | 자율주행 연구에 널리 쓰이는 공개 데이터셋. 차량·보행자·자전거 등의 바운딩박스 라벨 제공 |
| DontCare | KITTI 라벨에서 "평가 시 무시해야 하는 애매한 영역"을 표시하는 특수 클래스 |
| 클래스 (Class) | 객체의 종류 (예: 자동차, 보행자). AIDA MVP는 Car 단일 클래스만 사용 |
| 품질 점수 | AIDA가 산출하는 데이터셋 전체 품질 지표 (0~100점) |
| 재검수 우선순위 | 오류 가능성이 높은 순서대로 검수 자원을 배분하도록 AIDA가 제시하는 순위 |
| 품질 인증서 | 일정 기준을 충족한 데이터셋에 AIDA가 발급하는 납품용 인증 문서 |
